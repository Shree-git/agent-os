# Support

Agent OS is pre-release software for builders of local agent systems.

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Feature requests tied to a concrete agent workflow.
- Questions about embedding the CLI or local API in another project.

Before opening an issue:

- Run `agent-os doctor`.
- Run `agent-os state validate` if state already exists.
- Include the command, config excerpt, or API request that reproduces the problem.
- Use a temporary `--state` directory when possible.

Do not include secrets, provider API keys, private logs, or proprietary code in public issues.
