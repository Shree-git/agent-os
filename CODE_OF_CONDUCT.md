# Code Of Conduct

Agent OS contributors are expected to keep project discussion professional, specific, and useful.

## Expected Behavior

- Be respectful when disagreeing.
- Keep feedback focused on code, docs, design, reproducibility, and user impact.
- Assume good intent, but ask for clarification when behavior or claims are unclear.
- Help maintainers keep issues and pull requests actionable.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Sharing exploit details for unresolved vulnerabilities in public issues.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and issues that violate this code. Maintainers may also block users from participating in the project when behavior creates risk for contributors or users.

Security issues should follow `SECURITY.md`.
